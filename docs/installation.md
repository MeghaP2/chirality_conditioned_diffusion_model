# Installation

## Stable release

To install chirality_aware_conformer_generation, run this command in your terminal:

```sh
uv add chirality_aware_conformer_generation
```

Or if you prefer to use `pip`:

```sh
pip install chirality_aware_conformer_generation
```

## From source

The source files for chirality_aware_conformer_generation can be downloaded from the [Github repo](https://github.com/MeghaP2/chirality_aware_conformer_generation).

You can either clone the public repository:

```sh
git clone https://github.com/MeghaP2/chirality_aware_conformer_generation
```

Or download the [tarball](https://github.com/MeghaP2/chirality_aware_conformer_generation/tarball/main):

```sh
curl -OJL https://github.com/MeghaP2/chirality_aware_conformer_generation/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd chirality_aware_conformer_generation
uv sync
```
